# Eklenti (plugin) nedir?
Skill, komut, subagent ve hook'ları tek pakette toplar; başka projeye kurulabilir.
Bu klasördeki `hafiza-eklentisi`, proje-hafizasi skill'inin paketlenmiş kopyasıdır.
Deneme: `claude --plugin-dir ./eklenti/hafiza-eklentisi`
Skill, eklentide `/hafiza-eklentisi:proje-hafizasi` adıyla görünür.
