# Bağlam

**Amaç:** Claude Code'u öğrenmek için güvenli, küçük bir oyun alanı.
**Ürün:** Terminalden not ekleyen/listeleyen/silen CLI.
**Kapsam:** CLI + yerel web arayüzü (MCP araçlarını denemek için, bkz. karar 0004).
**Kapsam dışı:** Kullanıcı hesabı, senkronizasyon, uzak/üretim sunucusu.
**Ekler:** Fotoğraf, ekran görüntüsü vb. bu klasörde (`docs/baglam/`).
**Kullanıcı:** Tek kişi (öğrenen).
**Başarı ölçütü:** Her Claude Code kavramı için çalışan bir örnek dosya olması.
